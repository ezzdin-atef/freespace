Features

Everything taking up space, in one place.

Built in Rust for speed, with a clear interface that tells you what each item is and how to get it back.

Scans in seconds

Reads a whole drive in parallel: millions of files with live progress, not a coffee break.

Grouped cleanup

Temp files, caches, build output, node_modules, logs, crash dumps and Windows leftovers, by category.

Space usage treemap

Browse folders biggest-first and see where the space really went. Tick any folder to remove it.

Large files

Find the forgotten ISOs, videos and archives eating your drive, sorted by size.

Uninstall apps fully

Remove desktop and Store apps, then clear the folders they leave behind.

Recycle Bin mode

Send deletions to the Recycle Bin instead, and get a full report after every clean.

Safety first

Every item is labelled before you touch it.

Nothing is deleted until you tick it and confirm. Every delete is checked against the safety rules again right before it runs.

Safe

Regenerated automatically or never needed again.

  • Temp files and caches
  • Build output and node_modules
  • Windows Update downloads
Review

Probably fine to remove, but worth a look first.

  • Large files and old downloads
  • Logs and crash dumps
  • Leftovers from uninstalled apps
Do not delete

Protected. Freespace will never remove these.

  • Windows and installed programs
  • Your profile folders
  • Git repositories

How a folder earns its label.

No guessing from folder names alone. Each candidate is checked against the project around it before you ever see it.

  1. Scan

    Walks the drive in parallel, without following links.

  2. Match

    target only counts next to Cargo.toml, bin next to a .csproj.

  3. Check

    Is there a lockfile? Is it committed to git? Is the path protected?

  4. Label

    Safe, Review or Do not delete, with a reason and a restore command.

  5. You decide

    Nothing goes until you tick and confirm. Each delete is re-checked as it runs.

A scan can reach repos you do not trust, and a repo's config can make git status run programs. So Freespace only reads the files.

Uninstall all of it

Keeps watch from the tray

Close the window and it stays in the tray. It repeats your last scan on the schedule you pick, from 30 minutes to a day, and waits while you are working. A rescan only reads the disk.

Room to change your mind

Package manager caches

These grow quietly across every project you touch. Packages download again the next time a project needs them. Green is Safe; amber is Review, because the next build has more to fetch.

Windows Update cache

Downloaded updates in SoftwareDistribution\Download and the Delivery Optimization cache. Windows fetches again whatever it still needs.

Browser and app caches

Chrome, Edge, Brave, Firefox and Opera, plus VS Code, Cursor, Discord, Slack, Teams, Spotify and JetBrains IDEs. Passwords, history and cookies are not touched.

node_modules + lockfile, target, .next, npm cache, Windows Update downloads

Review

Common questions.

How do I free up disk space on Windows 11 or Windows 10?

Scan your drive with Freespace, review what it finds by category, and tick what to remove. Temp files, browser caches, Windows Update downloads, package manager caches and build output are good places to start. Every item is labelled, and nothing is deleted until you confirm.

What is taking up space on my C drive?

The Space usage page lists folders biggest-first beside a treemap, so you can open any folder and see where the space went. The Large files page finds files of 512 MB or more, such as old ISOs, virtual disks and archives.

Is it safe to delete node_modules?

Yes, if the project has a lockfile, because npm ci, pnpm install or yarn install restores the exact versions. Freespace looks for the lockfile first. Without one, node_modules is marked Review, since a reinstall may pick different versions.

Is it safe to clear the npm, pip or Cargo cache?

Yes. Package manager caches hold downloads, which come back the next time a project needs them. Freespace marks larger stores such as Gradle, Maven, NuGet packages and the pnpm store as Review, because your next build has more to fetch.

Can I delete the Windows Update cache?

Yes. Downloaded updates in SoftwareDistribution\Download can be deleted, and Windows downloads again whatever it still needs. Cleaning this folder needs administrator rights, which Freespace asks for when it starts.

Can I delete .log and .dmp files on Windows?

Usually. Old log files and crash dumps are only useful for debugging. Freespace marks logs written in the last 7 days as Review, and skips database journals that only look like logs, because deleting those corrupts data.

Will clearing the browser cache delete my passwords?

No. Freespace only removes cache folders from Chrome, Edge, Brave, Firefox and Opera. Passwords, history and cookies are not touched. Close the browser first so its files are not in use.

Can I undo a delete?

Yes, if you choose the Recycle Bin option in the confirm dialog, which moves items there instead of deleting them permanently. The space only comes back once you empty the bin.

Is Freespace free?

Yes. Freespace is free and open source under the MIT license, with no account, no ads and no telemetry. It runs on Windows 10 and 11, 64-bit.

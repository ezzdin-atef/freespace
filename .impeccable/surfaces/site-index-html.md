Scope: marketing landing page, Persuade mode. Audience: Windows developers first, everyone else second. Action: download the installer. Proof: an interactive drawing of a project's anatomy, a true description of the checks, a spec list. Constraints: static HTML in site/, works without the GitHub API.

## Direction contract

THESIS: User-pinned: clean, modern, flat and rounded, with drawings and a technical voice, and no screenshots. The page explains how a folder earns its label instead of showing the app.

OWN-WORLD: Indigo with its tints on white, dark ink tiles, safety colours only on labels. Geist and Geist Mono. Large radii, no shadows, inline SVG drawings.

STORY: The visitor sees their project broken down, understands the checks, trusts the labels, and downloads.

FIRST VIEWPORT: Headline and download on the left. On the right, a dotted panel with a folder, tree elbows to tickable rows, and a disk gauge that responds.

FORM: Brief-pinned, replaces the earlier roll (seed key 8d29cedd). Code-led. Signature interaction: ticking a row moves the gauge.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
